# 0단계 · 브레인스토밍 (컨셉 발산 → 수렴 → 락)

> 파이프라인에서 가장 중요한 단계. 여기서 방향을 못 잡으면 이후 작업이 전부 헛돈다.

## 입력 / 출력
- **입력:** 주제 + 사용자의 방향성 아이디어(있으면 최우선 반영)
- **출력:** 확정된 핵심 컨셉 **1개** (lock)

## 규칙
1. **컨셉 레벨로만 제안한다.** 후보마다 _이름 / 한 줄 훅 / 왜 주제·의미에 맞나_ 만.
   색·비율·디테일 등은 절대 미리 꺼내지 않는다.
2. **한 번에 2~3개씩**, 결을 일부러 다르게 제안한다 (예: 전통형 / 사물형 / 정서형 등 축을 갈라서).
3. 피드백을 받으면 **축을 바꿔 다시 발산한다.** 점검할 피드백 축:
   - 디자인 제작 용이성 (그리기 쉬운가)
   - 임팩트 (누가 봐도 "와—" 하는가)
   - 참신성 (특이한가 / 일반적이지 않은 내러티브인가)
   - 귀여움
   - 의미·주제 정합 (담아야 할 가치를 담는가)
   - **사용자 본인의 메타포 — 나오면 최우선.**
4. **컨셉 1개가 확정되기 전엔 1단계(브리프)로 절대 넘어가지 않는다.**

## 흐름
컨셉 후보 제시 → 사용자 피드백 → 축 바꿔 재발산 → … → 사용자가 하나 고름(lock) → 비로소 디테일 단계로.
