# 1단계 · 디자인 기획 — `character` 모드 (캐릭터 제안)

> 주제가 **캐릭터 제안**을 요구할 때 사용. 캐릭터는 **항상 Soul로 학습·재사용**한다 (1회성 생성 X).
> 출력은 2단계(구성)·3단계(Soul 캐릭터 생성)의 입력이 된다.

---

## 0. 입력 변수
- `{{TOPIC}}` : 시험 주제 (한 줄)
- `{{CONSTRAINTS}}` : (선택) 발표 시간 / 슬라이드 수 / 제출 규격
- `{{AUDIENCE}}` : (선택) 평가자/청중

## 2. 출력 (항목 고정, 형식 미정)

### 2-1. 공통
- 🎯 **concept** : 주제 한 문장 컨셉 + 키워드 3개
- 👥 **audience & tone** : 타깃 + 톤앤매너 + 톤 키워드 3개
- 🎨 **colors** : primary / secondary / accent / neutral (HEX) + 선정 이유
- ✍️ **typography** : heading / body 폰트 방향 + 이유
- 📐 **layout** : 그리드·여백 / 구도 원칙 / do · dont

### 2-2. 캐릭터 (모드 전용)
- **character.role** : 캐릭터가 맡는 역할/포지션
- **character.personality** : 성격·태도
- **character.appearance** : 외형 (체형/연령/특징)
- **character.outfit** : 복장·소품
- **character.expression** : 주요 표정·포즈 방향
- **character.symbolism** : 주제와의 연결 (왜 이 캐릭터인가)
- **character.soul_refs** : Soul 학습용 레퍼런스 방향 (필요한 각도·표정 세트)

## 3. 다음 단계로의 연결
- **공통** `colors`·`typography`·`layout`·`tone` → 2단계 구성 가이드 & 3단계 전체 톤
- **캐릭터** `character.*` → 3단계 **Soul 학습 후** 캐릭터 이미지 생성 / 2단계에서 캐릭터 등장 슬라이드 설계
