# 2단계 · PPT 구성 — `character` 모드

> 입력: 1단계 디자인 브리프(캐릭터 포함) + 시험 주제 → 출력: 슬라이드별 구성안
> 캐릭터가 발표 전반의 **가이드/내레이터**로 등장. 어느 슬라이드에 어떤 모습으로 나올지 함께 설계한다.

---

## 0. 입력 변수
- `{{TOPIC}}` : 시험 주제
- `{{DESIGN_BRIEF}}` : 1단계 출력 (concept / tone / layout / **character**)
- `{{SLIDE_COUNT}}` : (선택) 목표 슬라이드 수
- `{{DURATION}}` : (선택) 발표 시간

## 2. 출력 형식 (임시 — 조정 가능)

### 2-A. 전체 흐름 (Storyline)
```
표지(캐릭터 등장) → 목차 → 캐릭터 소개 → [도입/배경] → [본론 1..N] → [정리/결론] → 마무리(캐릭터 클로징)
```

### 2-B. 슬라이드별 구성표
| # | 슬라이드 역할 | 핵심 메시지 (1줄) | 담을 내용 (불릿) | 캐릭터 등장 | 캐릭터 포즈·표정 | 비주얼 메모 |
|---|---------------|-------------------|------------------|-------------|------------------|-------------|
| 1 | 표지 | | | O | | |
| 2 | 목차 | | | X | | |
| 3 | 캐릭터 소개 | | | O | | |
| … | | | | | | |

**항목 설명**
- **캐릭터 등장**: O / X — O인 슬라이드만 3단계 Soul 캐릭터 컷 대상
- **캐릭터 포즈·표정**: 그 슬라이드에서 캐릭터가 어떤 모습인지

## 3. 다음 단계로의 연결
