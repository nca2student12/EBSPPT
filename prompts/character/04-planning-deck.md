# 3단계 · 기획안 → PDF

> 확정 캐릭터와 에셋으로 8페이지 기획안을 만들고 PDF로 제출.

## 입력 / 출력
- **입력:** 확정 키비주얼 + 캐릭터 시트 + 굿즈 목업 + 텍스트
- **출력:** 8페이지 기획안 PDF

## 8페이지 구성 (마리멀즈 스타일 레퍼런스)
**앞 5장 = 캐릭터 소개 시트 / 뒤 3장 = AI·기술·클로징**

1. **표지** — 키비주얼 1컷 + 제목 + 대표 카피
2. **OVERVIEW + BACKGROUND STORY** — 컨셉/세계관 텍스트 정리
3. **캐릭터 소개 + 캐릭터 시트** — 대표컷 + Turnaround / Emotion
4. **굿즈 목업 ①** — 스티커 시트, 노트북 데코
5. **굿즈 목업 ②** — 마테(워시)테이프 / 폰케이스·배경 / 키링 / 머그 / 마우스패드
6. **AI 활용 프리뷰** — 제작 과정 타임라인 + 단계별 사용 AI를 구조화해서 보여줌 (이 기획의 차별점 프리뷰)
7. **기술 자랑** — Claude Code를 오케스트레이터로, 힉스필드(이미지생성)를 **MCP로 연결**, **바이브 코딩**으로 재현 가능한 **커스텀 제작 툴**을 만들어 썼다는 점 강조
8. **마무리** — 잘 나온 키비주얼 + 감성 카피 한 줄

## 에셋 일관성
- 모든 캐릭터 에셋은 **확정 키비주얼을 레퍼런스**로 생성해 눈·색·비율을 통일.
- 시트/목업은 `outputs/`에 역할이 드러나는 파일명으로 저장.

## 빌드 방식
- HTML 8섹션 덱(1페이지=1섹션, 가로 비율) 작성 → 로컬 이미지 임베드 → **Edge 헤드리스로 PDF 출력**
  - 예: `msedge --headless --print-to-pdf=out.pdf --no-pdf-header-footer file.html`
- 텍스트(특히 한글)·레이아웃 정밀도가 필요한 P6·P7은 생성 이미지가 아니라 **CSS 인포그래픽**으로 구성.
