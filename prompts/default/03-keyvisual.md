> 입력: 1단계 브리프(visual_motif) + 2단계 구성표(비주얼 필요 = O 슬라이드)

## 3. 실행 절차
1. **슬라이드 순회** — `{{SLIDE_VISUALS}}` 각 행마다:
   - `1-1 공식`에 `비주얼 메모` 주입 (+ `1-2 일관성 규칙`)
   - 모델로 키이미지 생성
2. **통일감 점검** — 전체 이미지가 같은 톤·색을 유지하는지 확인
3. **매핑 수집** — `슬라이드# → 이미지 URL` 표로 정리
