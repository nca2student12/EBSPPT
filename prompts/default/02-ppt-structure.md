# 2단계 · PPT 구성 — `default` 모드

> 입력: 1단계 디자인 브리프(키비주얼 포함) + 시험 주제 → 출력: 슬라이드별 구성안
> 표준 발표 흐름 + 필요한 슬라이드에만 정적 키비주얼을 배치한다.

---

## 0. 입력 변수
- `{{TOPIC}}` : 시험 주제
- `{{DESIGN_BRIEF}}` : 1단계 출력 (concept / tone / layout / **visual_motif**)
- `{{SLIDE_COUNT}}` : (선택) 목표 슬라이드 수
- `{{DURATION}}` : (선택) 발표 시간

## 2. 출력 형식 (임시 — 조정 가능)

### 2-A. 전체 흐름 (Storyline)
```
표지 → 목차 → [도입/배경] → [본론 1..N] → [정리/결론] → 마무리
```

### 2-B. 슬라이드별 구성표
| # | 슬라이드 역할 | 핵심 메시지 (1줄) | 담을 내용 (불릿) | 비주얼 필요? | 비주얼 메모 |
|---|---------------|-------------------|------------------|--------------|-------------|
| 1 | 표지 | | | | |
| 2 | 목차 | | | | |
| 3 | | | | | |
| … | | | | | |

**항목 설명**
- **비주얼 필요?**: O / X — O인 슬라이드만 3단계 키이미지 대상
- **비주얼 메모**: 어떤 이미지/도식이 필요한지 한 줄

## 3. 다음 단계로의 연결
- **슬라이드별 구성표 전체** → 4단계 NotebookLM 초안 입력
- **비주얼 필요 = O 슬라이드** → 3단계 키이미지 생성 대상
- **1단계 톤/컬러/레이아웃** → 모든 슬라이드 일관 적용
