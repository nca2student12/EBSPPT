> 출력은 2단계(구성)·3단계(키이미지 생성)의 입력이 된다.

---

## 0. 입력 변수
- `{{TOPIC}}` : 시험 주제 (한 줄)
- `{{CONSTRAINTS}}` : (선택) 발표 시간 / 슬라이드 수 / 제출 규격
- `{{AUDIENCE}}` : (선택) 평가자/청중

## 2. 출력 (항목 고정, 형식 미정)

### 2-1. 공통
- 🎯 **concept** : 주제 한 문장 컨셉 + 키워드 3개
- 👥 **audience & tone** : 타깃 + 톤앤매너 + 톤 키워드 3개
- 🎨 **colors** : primary / secondary / accent / neutral (HEX) + 선정 이유
- ✍️ **typography** : heading / body 폰트 방향 + 이유
- 📐 **layout** : 그리드·여백 / 구도 원칙 / do · dont

### 2-2. 키비주얼 (모드 전용)
- **visual_motif.direction** : 전체 비주얼 방향
- **visual_motif.key_objects[]** : 핵심 소재/오브젝트
- **visual_motif.style** : 사진/일러스트/3D/추상 등
- **visual_motif.mood** : 분위기

## 3. 다음 단계로의 연결
- **공통** `colors`·`typography`·`layout`·`tone` → 2단계 구성 가이드 & 3단계 전체 톤
- **키비주얼** `visual_motif.*` → 3단계 키이미지 생성 / 2단계에서 비주얼 슬라이드 설계
