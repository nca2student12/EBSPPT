# 2단계 · PPT 구성 — `video` 모드 (영상 키프레임)

> 입력: 1단계 디자인 브리프(키프레임 포함) + 시험 주제 → 출력: 슬라이드별 구성안
> 영상의 **키프레임 시퀀스**를 슬라이드 흐름으로 풀어낸다. 키프레임이 어느 슬라이드에 배치되는지 매핑한다.

---

## 0. 입력 변수
- `{{TOPIC}}` : 시험 주제
- `{{DESIGN_BRIEF}}` : 1단계 출력 (concept / tone / layout / **video.keyframes**)
- `{{SLIDE_COUNT}}` : (선택) 목표 슬라이드 수
- `{{DURATION}}` : (선택) 발표 시간

## 2. 출력 형식 (임시 — 조정 가능)

### 2-A. 전체 흐름 (Storyline)
```
표지 → 목차 → [영상 컨셉 소개] → [키프레임 시퀀스 1..N] → [정리/결론] → 마무리
```

### 2-B. 슬라이드별 구성표
| # | 슬라이드 역할 | 핵심 메시지 (1줄) | 담을 내용 (불릿) | 키프레임 매핑 | 키프레임 화면 메모 |
|---|---------------|-------------------|------------------|----------------|--------------------|
| 1 | 표지 | | | - | |
| 2 | 목차 | | | - | |
| 3 | 키프레임 #1 | | | KF1 | |
| … | | | | | |

**항목 설명**
- **키프레임 매핑**: 이 슬라이드에 들어갈 키프레임 번호 (1단계 `video.keyframes[]`와 연결)
- **키프레임 화면 메모**: 그 키프레임이 보여줄 장면

## 3. 다음 단계로의 연결
- **슬라이드별 구성표 전체** → 4단계 NotebookLM 초안 입력
- **키프레임 매핑된 슬라이드** → 3단계 키프레임 이미지 생성 대상
- **1단계 톤/컬러/레이아웃** → 모든 슬라이드 일관 적용
